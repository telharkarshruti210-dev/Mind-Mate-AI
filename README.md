# MindMate AI

MindMate is an AI-powered platform designed to provide a minimal, clean, and interactive user experience.

## 🚀 Tech Stack
* **Backend:** Python (Flask)
* **Frontend:** HTML5, CSS3, JavaScript

## 📂 Project Structure
* `app.py` - Core Flask backend and API integration logic.
* `templates/` - HTML files for the user interface.
* `static/` - CSS stylesheets and JavaScript files.
